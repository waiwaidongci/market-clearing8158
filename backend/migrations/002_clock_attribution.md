# 002 离线时钟漂移与营业日归属

沿用 `Base.metadata.create_all` 自动补建缺失表；本次只新增表，不修改既有表字段，
已存在的数据库重启后端即会建出下列两张表，无需手工迁移。

- `clock_calibrations`：收银设备校时记录。每次联网校时登记一条设备时间 ↔ 标准时间，
  按 `(device_id, device_time)` 唯一约束去重；偏差秒数在写入时由标准时间减设备时间算出。
  记录只存校时事实，允许乱序补录，归属计算时再按设备时间排序。
- `pending_attributions`：食堂核销营业日挂起台账。`(dataset_id, transaction_key)` 唯一，
  记录跨日待定 / 缺校时依据两类挂起原因、真实时间区间与归属依据。每次校时补录后在同一
  事务内对该数据批次整体替换（先删后插），配合数据集行级锁保证并发重试不重复计账。
- `attribution_snapshots`：每个数据批次一行，保存最近一次全量营业日归属（食堂核销侧）的
  JSON 快照。下一轮补录据此逐笔比较状态与营业日，精确算出「受影响营业日」，含已归属流水
  的跨日改归属；与挂起台账在同一事务内替换。

挂起流水不进入 `runs.result` 当日双账清分，仅在清分结果的「食堂核销营业日归属」表与
挂起台账中回查；校园卡账沿用卡中心原日期，不写挂起表。
